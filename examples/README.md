# Examples

Each notebook reproduces, in Python with pandas, examples of the R package lme4 taken from
its documentation, vignettes and well-known tutorials, and checks the results against the
output of R (lme4 2.1.0).

| notebook | topic |
|---|---|
| [01_linear_mixed_models](01_linear_mixed_models.ipynb) | sleepstudy and Dyestuff: REML vs ML, correlated/uncorrelated slopes, `anova`, singular fits, diagnostic plots |
| [02_crossed_and_nested_random_effects](02_crossed_and_nested_random_effects.ipynb) | Penicillin (crossed), Pastes (nested), `isNested`, InstEval (73 421 obs.), model structure via `getME` |
| [03_binomial_glmm](03_binomial_glmm.ipynb) | cbpp, Laplace vs adaptive Gauss–Hermite quadrature, links, overdispersion, odds ratios, VerbAgg, toenail |
| [04_count_data_poisson_negative_binomial](04_count_data_poisson_negative_binomial.ipynb) | grouseticks, observation-level random effects, `glmer.nb`, offsets, Gamma GLMM |
| [05_nonlinear_mixed_models](05_nonlinear_mixed_models.ipynb) | `nlmer`: Orange (SSlogis), user-defined models with gradients, Theoph (SSfol) |
| [06_prediction_and_simulation](06_prediction_and_simulation.ipynb) | `predict` (incl. `se_fit`), `re_form`, new levels, `simulate`, `bootMer`, power analysis by simulation |
| [07_inference_profiles_and_tests](07_inference_profiles_and_tests.ipynb) | likelihood-ratio tests, `drop1`, profile likelihood and its plots, Wald/profile/bootstrap intervals, p-values |
| [08_covariance_structures_and_diagnostics](08_covariance_structures_and_diagnostics.ipynb) | `us`/`diag`/`cs`/`ar1`, `rePCA`, convergence troubleshooting, `allFit`, `lmList`, influence |

## Structure of a notebook

1. **Source**: where the example comes from (with a link), and the original R code.
2. **Python**: the same analysis with `lme4` for Python and pandas.
3. **Check**: the numbers are compared with reference values produced by R
   (`examples/reference/<notebook>.json`, generated by `examples/r/<notebook>.R`).

The notebooks double as tests: CI installs the package and executes every notebook; a failed
comparison raises an error.

## Validation (in Docker)

The validation image contains R 4.6.2 with lme4 2.1.0 and lme4 for Python built from the
repository:

```bash
docker build -t lme4-validate -f tools/validate/Dockerfile .
docker run --rm -v "$PWD:/work" lme4-validate            # R references + notebooks + tests
docker run --rm -v "$PWD:/work" lme4-validate refs       # regenerate the R references only
docker run --rm -v "$PWD:/work" lme4-validate notebook 01_linear_mixed_models.ipynb
```

Set `-e LME4_REINSTALL=1` to rebuild the package from the mounted repository first.

## Running the notebooks

pip install --pre "lme4[plots]" jupyter
